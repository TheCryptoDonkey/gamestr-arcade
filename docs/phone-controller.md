# Phone controllers

The cabinet and both public web editions offer **Pair phone**. The QR opens Joystick in the phone's browser; a six-character code displays as `ABC DEF`. The controller-options page retains the exact session/version/broker and offers browser installation or an already-installed native app. App Store/Google Play links remain unavailable until Joystick's public store listings exist.

The cabinet uses the existing Joystick v2 host SDK and validates a narrow input snapshot before forwarding it from the trusted shell to the active isolated game view. The game sees a standard virtual Gamepad; physical input remains usable. Keyboard/pointer translation still follows the game's manifest adapter. Input does not grant Nostr signing or wallet permission. Native process/AppImage games are not controlled by this browser bridge.

The Joystick SDK has no default relay, so the arcade names its own: `controllerRelay` in `arcade.config.json` (default `wss://controller.pallasite.app/`). The owner's hosted relay accepts game screens only from the owner's own sites, so the Electron cabinet, which loads from a file, presents `https://arcade.600.wtf` as the `Origin` on WebSockets to the production relay and to nothing else (`src/main/relay-origin.ts`). A relay you point the arcade at is left alone. The relay forwards only a closed vocabulary of labels and names, so the built-in menu and game specs and the shipped game profiles use words from it (`scripts/check-owner-games-vocab.mjs` in the Joystick repository runs them); a game definition with other labels still pairs, but the phone shows its own default for those buttons.

The public catalogue can be navigated with the paired phone. A publisher must explicitly implement `gamestr-controller-v1` to keep that connection in its own page. Hang On, Fren is the first integrated game. Its controller profile changes labels and layout when play moves into the publisher window. Other games disclose that only catalogue pairing is available. Popups still need the browser's normal permission; modified clicks open an independent game.

The input handshake is separate from `gamestr-auth-v1`. It pins the exact opened child and publisher origin, validates the game's declarative profile, and transfers a dedicated MessageChannel. Publisher clients pin permitted Arcade origins. Closing a channel or losing its heartbeat releases input; profile/geometry changes start neutral. Existing login, signing revocation, selected-account and wallet approval journeys retain their own authority boundaries.

The open draft NIP, schema, shared fixtures and portable browser/Swift/Kotlin reference are at [nostr-game-controller](https://github.com/forgesworn/nostr-game-controller). No NIP number or event-kind allocation is claimed. SDK tarballs are pinned locally with MIT licence and hashes in `vendor/joystick/provenance.json`; no registry publication is claimed.

Validation: complete config/schema/type/unit/Electron/web build gates, both editions' initial JavaScript budget and CSP checks, and 57 browser journeys including actual cross-origin input/profile handoff and input-channel neutralisation. Physical cabinet and publisher gameplay remain a separate acceptance check.

Version 0.2.1 restricts phone catalogue navigation and activation to game cards, play links and Arcade/Scores navigation. Pairing cannot activate focused account, signing or payment controls; an open dialog suspends catalogue navigation. The regression covers these focused approval controls. The 0.4.1 profile SDK also retains physical HAT directions and rumble beside the phone.

Game definitions own their default phone controls in `controller.profile`, alongside name, URL, artwork, players, scoring and capabilities in the same `game.json`. The schema and publisher UI validate the complete definition plus profile semantics. The NIP-89 submission carries the whole definition in `content.gamestr_manifest`; it does not publish a second controller event. Cabinet and public catalogue select that profile at launch; the running game may replace it for its active session. `games/hang-on-fren/game.json` is a reviewed catalogue cache of the publisher file. Gamestr.io still needs adoption of the proposed extension.
